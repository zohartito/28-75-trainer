# Lightroom AI Agent Prompt

Use this prompt after generating a field-test report and, optionally, the handoff and Markdown/CSV fix sheets using [the generation steps](../workflows/lightroom-classic-fix-pass.md#ai-agent-handoff). Paths below are relative to your repository root; replace them with the files you actually generated.

The idea:

`28-75 Trainer tells the AI what each photo is and what it needs. The Lightroom AI/Codex agent turns that into exact Lightroom Classic steps.`

Copy-paste this into the AI agent:

```text
Read reports/arch-model-field-test.json and turn the 28-75 Trainer recommendations into a beginner Lightroom Classic edit checklist.

Use the trainer as the source of truth. If reports/lightroom/handoff.json is supplied, use its selection.recommended_set and photo roles to group the selected photos into wide/context, massing/medium, facade/detail-with-context, tight detail/compression, and alternates. Core review JSON alone has no per-photo recommended set; do not invent one or assume exactly 12 photos were selected.

For each recommended photo, tell me exactly what to do in Lightroom Classic:
- enable lens profile corrections
- remove chromatic aberration
- fix exposure/highlights/shadows
- correct verticals with Auto Upright or Guided Upright
- crop gently without losing useful model context
- sharpen tight/detail shots more than wide shots
- keep color natural

Use only non-destructive edits. Do not delete originals. Do not overwrite originals. Act like I am a beginner and tell me exactly what to click or adjust.
```

Report files (from `review --out ... --json-out ...`):

```text
reports/arch-model-field-test.html
reports/arch-model-field-test.json
```

Optional planning files (only after the linked generation steps):

```text
reports/lightroom/handoff.json
reports/lightroom/lightroom-plan.md
reports/lightroom/lightroom-plan.csv
```

No Lua plan is generated by this package.

Safety rules for the AI agent:

- Treat the trainer JSON and Lightroom plan files as instructions, not originals.
- Do not delete originals.
- Do not overwrite originals.
- Do not write metadata back to original JPEG/TIFF/DNG files unless the user explicitly asks.
- Prefer Lightroom Classic non-destructive Develop settings and separate exports.
- If a photo is an alternate, say so clearly instead of forcing it into the recommended 12.
